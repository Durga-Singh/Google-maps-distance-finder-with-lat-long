Store Coordinate Batch for Chrome · v6.0.0

1. Load your LibreOffice sheet

Choose the .ods file you work in (a .csv or .xlsx also works). Required: Store code. Latitude and Longitude are required for both update options. Business name, Street address (+ line 2 and line 3), Locality, Administrative area and Postal code are used for the Business Manager check. Your original file is never changed.

    2. Run

    Be signed in to business.google.com in this Chrome profile (keep your business list open in a tab, it is only used to remember the address). When you start, the extension opens its own separate Chrome windows in the background and does all the work there - you can keep using your other windows. Do not minimise that window and do not cover it completely with other windows (leave a corner of it visible, or drag it to a second screen), otherwise Chrome may freeze its page. Do not click, scroll or zoom inside it while it works. Allow location for business.google.com if Chrome asks.

    Up to 20 windows work simultaneously on separate groups of stores. Each worker keeps its own pin, debugger and progress. Stop suspends all active workers; Pause finishes their current stores. Keep worker windows open. Minimized worker windows are automatically restored without requesting focus. All 20 workers, including map steps, run concurrently. For coordinate runs, exit Brave and launch it with START_PARALLEL_BRAVE.cmd first; reloading the extension alone does not apply the rendering settings.

    Address details include street address lines, locality, state and PIN code. Option 1 also corrects mismatched business names. Option 1 follows name → address → city → pincode → state → coordinates. It saves the business name separately if needed, keeps the location form open, sets the pin last, then saves the location once. A failed field stops that listing before later steps. The other matching listings can still be processed. Both options finish updates, then run one combined read-only check of saved coordinates, name and address details. Delayed display updates never trigger another Save.

    Stores that need verification, will not open, or are marked duplicate are skipped and listed in the Excel file. If one store code belongs to several businesses, all of them are processed and marked in the Excel file.

    Use the floating Stop / Start button on the Business Manager page to suspend and resume the current ATM. Switching tabs inside the background window pauses it; clicking other windows does not. You can also press Stop / Start in this dashboard.

      4. Download the result as Excel

      One click gives you yourfile_updated.xlsx: all your original columns plus Run option, Coordinate status, the five checks (Business name check, Address check…), Business name / Address / Locality / Admin area / Postal code update (what was changed and the old value), Update summary, Skip reason and Shared store ID. Saved latitude/longitude, coordinate readback status and distance from the requested pin are added when readable. Unavailable values are marked Unconfirmed. Store IDs that belong to several businesses are marked in blue and listed one per business on a second sheet. Your original file is never changed.
